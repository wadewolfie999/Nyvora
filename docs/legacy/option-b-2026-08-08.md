# Historical Environment Decision Record

> This file preserves the earlier Option B/Option C decision. It is not current
> desired state. Systems Alchemy was the surrounding environment name.

Status recorded: 2026-08-08.

The earlier plan used Ansible plus a thin CLI for `mac-node`, `vps-node`, and
the then-current `comp-node` identifier. It prioritized restoring SSH, gathering
facts, persisting reverse SSH, then adding collaborator accounts. Cockpit was
deferred and required to remain private and subordinate to configuration as
code. At that time no Ansible skeleton, Cockpit installation, route change,
SSH rewrite, persistent tunnel, service change, or account mutation had been
implemented.

The mature NC-M0 architecture supersedes this sequence while preserving its
inspect-first, explicit-target, rollback, and verification discipline.
