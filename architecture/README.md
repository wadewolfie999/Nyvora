# Nyvora architecture baseline

This directory is the repository entry point for the adopted Nyvora
architecture package:

- [`NYVORA-Architectural-Baseline-v1.0.1-corrected.docx`](NYVORA-Architectural-Baseline-v1.0.1-corrected.docx) — controlling baseline;
- [`CHANGE-CONTROL.md`](CHANGE-CONTROL.md) — architecture change process;
- [`SUPERSESSION.md`](SUPERSESSION.md) — relationship to older repository material.

The corrected DOCX is authoritative over older repository guidance where the
two conflict. Older files remain preserved implementation and historical
context until they are reconciled through the change process; they must not be
silently interpreted as the current architecture.

The source DOCX was authored outside this repository and remains unchanged.
The corrected edition preserves its baseline ID, records the owner adoption
instruction received on 30 August 2026, and does not claim live deployment or
operational qualification.
